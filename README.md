## Language Detection Using Natural Language Processing

## Project Overview-

This project focuses on identifying the language of a given text using Natural Language Processing (NLP) techniques.
The project uses a dataset containing text samples and their corresponding language labels. The data is explored and prepared before applying text vectorization and a machine learning classification model.

## Objectives-

Explore and understand the language detection dataset.
Identify missing values and examine language distribution.
Convert text data into numerical features.
Train a machine learning model to predict languages.
Build an interactive text input interface for language prediction.

## Technologies Used-

Python
Pandas
NumPy
Scikit-learn
CountVectorizer
Multinomial Naive Bayes
Jupyter Notebook
Git and GitHub

## Project Workflow-

Dataset loading
Data quality checks
Language distribution analysis
Feature and target separation
Text preprocessing and vectorization
Model training and evaluation
Language prediction for new text

## Expected Outcome-

The goal is to develop a system that accepts a text sentence and predicts its language using NLP and machine learning techniques.
